laz-tile-index interactive demo

A 2D walkthrough of what the library does on a real LAS file. Drag a query rectangle on the canvas to see which uniform-grid cells the index would read out-of-core, how many points it would scan inside those cells, and how many survive the bbox filter. Live data is synthetic so the page runs entirely in your browser. The actual library at github.com/daudee215/laz-tile-index runs the same algorithm on real .las / .laz files via laspy.
